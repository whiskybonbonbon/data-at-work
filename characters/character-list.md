# Character List

This document lists the characters in Data at Work and the technologies they represent. Names and designs may include provisional ideas from the initial concept stage.

## Protagonist

| Character | Technical motif | Story role | Defining traits |
|---|---|---|---|
| [Data (working name)](list/data.md) | Data | Newly created traveler and protagonist | Curious and slightly clumsy; searches for her purpose while being processed, transformed, stored, and transmitted |

> The story presents her as one continuous protagonist, but technical explanations distinguish her fictional continuity from real operations such as copying, transformation, and regeneration.

## Core Characters

| Character | Technical motif | Job metaphor | Technical focus |
|---|---|---|---|
| Bit | bit | Tiny inhabitant | A binary digit represented by either 0 or 1 |
| [Packet](list/packet.md) | packet | Transport capsule | A communication unit that carries data through a network |
| Thread | thread | Processing worker | A flow of instruction execution within a program |
| CPU | CPU | Central processing department | Hardware that executes instructions |

## Network District

| Character | Technical motif | Job metaphor | Technical focus |
|---|---|---|---|
| TCP | TCP | Reliability-focused delivery manager | A protocol that provides ordered, reliable byte-stream delivery using mechanisms such as acknowledgements and retransmission |
| UDP | UDP | Low-overhead delivery manager | A connectionless datagram protocol that does not itself provide retransmission or ordering |
| IP | IP | Addressing and forwarding specialist | Routes datagrams using network addresses |
| DNS | DNS | Guide | Resolves names to addresses and other records |
| Router | router | Traffic controller | Forwards packets toward their destinations |

TCP and UDP have contrasting personalities, but neither is universally better. The story should show that different applications need different transport characteristics.

| Character or organization | Technical motif | Job metaphor |
|---|---|---|
| HTML | HTML | Architect |
| CSS | CSS | Designer |

| Java | Java | Large-scale systems engineer |
| C | C | Veteran machine engineer |
| Rust | Rust | Safety-focused engineer |

Programming languages describe instructions; they do not perform processing by themselves. The story represents them as characters or organizations embodying their technical ecosystems while distinguishing them from programs, runtimes, and hardware that execute instructions.
