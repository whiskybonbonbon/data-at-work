# Data at Work

Data at Work is a creative project for developing characters, settings, and stories inspired by real-world systems, roles, and concepts.

## Character Template

Use [characters/character-template.md](characters/character-template.md) to design a character from their central concept through their visual design, motivations, relationships, abilities, and story arc.

The template also supports anthropomorphized characters by mapping the source concept's real features to the character's appearance, behavior, and narrative role. You do not need to complete every field: start with the sections marked with a star (`★`) and add detail as the story develops.

## Project Structure

```text
.
├── LICENSE.md
├── README.md
└── characters/
    ├── character-template.md  # Reusable character design worksheet
    └── list/
        └── data.md            # Character list and profile data
```

## Working with Characters

1. Copy `characters/character-template.md` when creating a new character profile.
2. Store character profiles and related data under `characters/`.
3. Use `characters/list/data.md` to maintain the character list or shared character data.

Keep filenames descriptive as the project grows so that each character and supporting document can be identified without opening the file.
